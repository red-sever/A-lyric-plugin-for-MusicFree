# MusicFree 智能歌词插件

插件安装文件：`MusicFree_SearchingLyric.js`  
插件显示名称：**歌词检索**  
版本：1.0.3（已经安卓兼容编译）

## 1.0.3：带前缀标题和自动加载

对“兰香如故：郁可唯-一曲微茫”，会先尝试原信息，再依次尝试“郁可唯 一曲微茫”和“一曲微茫”；已有合适结果就停止。搜索歌词与自动搜索共用这套逻辑，每次最多使用三个去重关键词，每个来源都沿用原先的接口。

会保留推断出的歌手用于结果校验，避免仅因歌手相同就选到其他歌；用于比较时会忽略明确的主题曲等括号说明，保留 Live 等版本信息。普通冒号和拉丁语连字符不一律当作前缀删除。

在 MusicFree 0.6.2 的 **侧栏 → 基本设置 → 歌词 → 自动搜索歌词** 开启开关。原音源未返回歌词时，播放器会调用本插件并自动加载，无需每首手动关联。已有歌词仍通常优先，插件不会直接修改这个播放器设置，也不会强制替换已有歌词。

24 项离线测试通过。以用户给出的完整标题实测，成功匹配“郁可唯 / 一曲微茫”，本次从 QQ 获取歌词，原文长度 768。网易云本次未得到通过匹配的结果，不能将此测试称为网易云搜索也已修复。1.0.3 使用与 1.0.2 相同的安卓编译方式，并通过了无 async/await/yield/生成器语法检查；本版本未另行在模拟器中运行。详见 `1.0.3测试记录.md`。

## 1.0.2 修复了什么

此前的 1.0.0、1.0.1 是含有 `async/await` 的开发源码。实际在电脑现有 Android 15 模拟器的 MusicFree 0.6.2 中复现：动态加载报 `async functions are unsupported`，导致插件未进入管理列表。本地安装界面仍可能显示成功。这是前两版缺少安卓兼容构建造成的，不是用户操作或 VPN 问题。

1.0.2 已将这些语法编译成普通函数和 Promise 状态机，并通过语法树检查，确认交付文件不含 async/await、yield 或生成器函数语法。

**只安装最新的 `musicfree-smart-lyrics-1.0.3-android.js`。名字带 `.source.js` 的开发源码不能直接安装到安卓版，源码现已移出交付目录。**

实测环境：已有 Android 15 x86_64 模拟器、官方 MusicFree 0.6.2。已验证插件目录加载、插件列表显示、安卓进程中的本地自检、真实联网搜索与歌词获取。测试关键词 `Adele - Hello` 返回 11 个匹配项，第一项 QQ 歌词获取成功，原文长度 2224。详见 [模拟器测试报告](模拟器测试报告.md)。

## 安装后没有变化：先验证这个入口

本插件只声明了 `supportedSearchType: ["lyric"]`，因此安装后不会添加首页按钮，也不会像 bilibili 音源那样出现在普通歌曲搜索中。它应出现在插件管理列表，以及**歌曲的歌词搜索面板**中。`srcUrl` 只提供远程更新，`getMediaSource` 只提供播放地址，两者都不是独立歌词插件的必需功能。

安卓版操作路径（按已核对的源码）：**播放一首歌 → 打开歌词页 → 点击歌词页底部的放大镜图标 → 选择“智能歌词（网易云·QQ）”**。

在这个面板输入 **`插件自检`** 并搜索，应出现 **“插件自检（无需联网）”**。只需确认列表出现该项即可，不必点击关联。这个检查不访问任何网站，能把“插件没有加载/入口不对”和“网络请求不通”区分开。

若插件管理列表里根本没有该名称或版本未显示为 1.0.3，则尚未确认更新安装成功。当前查阅的安卓版本地安装界面没有逐项检查安装函数返回的 `success` 字段，因此仅有“插件安装成功”提示不能证明插件已成功加载。

1.0.3 保持与旧版同名，重新从本地安装即可更新。安装前请关闭已打开的歌词搜索面板，再重新进入，让面板重新获取插件列表；必要时退出并重新打开 MusicFree。插件自检也可输入英文 `plugin-test`。

## 保留的功能改进

- 对照官方 `musicfree-plugin-dev` skill 和协议参考文档复核，仅保留歌词相关能力。
- 增加无需联网的“插件自检”搜索及本地测试歌词。
- 兼容 axios 直接导出和 `default` 导出形式。
- 去掉非协议必需的 `defaultSearchType`，普通歌曲搜索调用直接返回空结果，避免在不可见的普通搜索中请求歌词。
- 单个服务失败时继续使用另一来源；所有来源请求失败时抛出错误，并记录来源及失败原因。获取歌词失败不再一律静默返回 `null`。MusicFree 自身可能捕获错误而不弹窗，可在应用日志中查看。
- 先按安卓版源码的 CommonJS 包装函数进行离线测试，再在现有安卓模拟器的 MusicFree 进程中验证真实解析与方法执行。尚未连接用户手机。

## 安装

1. 将 `musicfree-smart-lyrics-1.0.3-android.js` 保存到运行 MusicFree 的设备。若下载器把后缀改成 `.txt`，请改回 `.js`。
2. 在 MusicFree 的“设置 → 插件设置”中选择“从本地安装插件”，选中该文件并启用。不同版本的入口文字可能略有区别。
3. 在歌词相关设置中开启“自动搜索歌词”。插件只提供歌词，因此不会出现在音乐音源搜索列表中；请先按上面的放大镜入口完成自检。
4. 播放一首原音源没有歌词的歌曲。MusicFree 会在需要时调用歌词搜索插件。

如果自动结果不合适，在歌曲的歌词操作菜单中进入搜索歌词/关联歌词入口，选择本插件，输入歌名或 **`歌手 - 歌名`**，再选中正确结果进行关联。关联操作由 MusicFree 保存。

已有歌词一般由 MusicFree 优先使用。安装这个插件并不会强制替换所有歌曲的歌词，也不会替换原来的音源插件。

## 插件设置

在插件的用户变量/设置入口填写以下值；留空即可使用默认设置。

| 选项 | 默认值 | 可填内容 |
|---|---|---|
| 歌词来源 `source` | `auto` | `auto` 双源；`netease` 仅网易云；`qq` 仅 QQ 音乐 |
| 歌词翻译 `translation` | `on` | `on` 开启；`off` 关闭 |
| 请求超时 `timeout` | `8` | 秒数，范围 3～30；线路较慢时可填 `20` |

翻译独立返回给 MusicFree；是否显示以及显示样式由播放器控制。更改设置后，如果当前歌曲命中了播放器自身的旧缓存，可以刷新歌词或重新关联。

## 匹配逻辑与适配

参考 MusicPlayer2 V2.78 的设计，独立实现 JavaScript 版本：

- 优先使用已选歌词结果的来源 ID 获取歌词。
- 需要检索时，有标题和歌手则搜索“歌手 标题”；只有标题则搜索标题；缺少标题且调用方提供本地文件路径/文件名时，使用不含音频扩展名的文件名。
- 对标题、歌手、专辑、文件名计算编辑距离相似度。权重依次为标题 0.4、歌手 0.4、专辑 0.3、文件名对标题 0.3、文件名对歌手 0.3，加上搜索顺序权重。最高分不足 0.3 时不采用。与原实现的实际代码一致，未将时长加入评分。
- 双源模式并行检索网易云和 QQ，按分数排序；同分优先保留网易云。获取某个结果的歌词失败时，根据该结果的完整元数据重新搜索，最多尝试另三个结果。
- 原文、翻译分别解析；QQ 返回的 HTML 实体与 JSONP 会被处理。纯音乐提示不作为歌词返回。
- 成功搜索结果在内存缓存 5 分钟，歌词缓存 30 分钟，各最多 100 项；并发相同请求会合并。失败不永久记录，后续可重试。

**自动匹配能力的边界：**当前查阅的 MusicFree 安卓源码在自动补歌词时，只调用 `search(歌名, 1, "lyric")`，且仅查看返回结果的前两项，再由播放器按歌手等信息选择。插件在这一入口拿不到原曲的完整歌手、专辑或文件名，无法完整复现 MusicPlayer2 的所有评分条件，也无法接管播放器的最终选择。手动输入“歌手 - 歌名”可以提高准确度；`getLyric` 收到完整元数据时会使用完整评分。插件没有通过内部全局变量绕过这一限制。

本插件为独立歌词源，不直接将 `.lrc` 写入歌曲目录。缓存及歌词关联由 MusicFree 管理。它不修改播放器、不操作 VPN，也不提供音乐播放地址。

## 验证结果（2026-10-18）

- Node 语法检查通过。
- 1.0.2 的 18 项离线测试通过，测试对象为编译后的安装文件，覆盖安卓版包装函数加载、无需联网的自检、两种 axios 导出形式、错误日志、插件协议、评分和过滤、双源、翻译解析、缓存、并发、超时配置、文件名回退、暂时失败重试及宿主调用流程。
- 1.0.0 曾在 Node 测试中以“陈奕迅 - 十年”为关键词，QQ 返回 17 个匹配项；这个结果不代表安卓版能够解析那份开发源码。1.0.2 已另行通过上文所述的真实安卓运行测试。
- 网易云公开搜索接口实际返回 HTTP 200 和业务码 200，但本次搜索结果与关键词不符，被评分规则过滤；网易云已知歌曲 ID 的歌词接口单独探测成功。**网易云的完整搜索到歌词流程尚未验证通过。**双源模式仍可采用 QQ 的结果。
- 联网测试过程中曾出现超时；可能与线路、VPN、接口状态等有关，未据此认定接口已失效。测试没有关闭或更改 VPN。
- 早期联网测试使用 Node `fetch` 适配 axios；1.0.2 的安卓联网测试则使用 MusicFree 自身提供的 axios。未在用户手机验证，尚未完成模拟器中本地文件选择安装和歌曲歌词页最终渲染的完整点击流程，不能保证所有网络、歌曲或应用版本均可用。
